# JISA Korea Internship Portfolio

전성현 × Remote Plus 일본 인턴십 포트폴리오입니다.

## GitHub Pages에 올리기

1. 이 폴더의 `index.html`, `styles.css`, `script.js`를 GitHub 저장소 최상위에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고, 업로드한 브랜치의 `/ (root)`를 지정합니다.
4. 저장 후 표시되는 공개 주소에서 사이트를 확인합니다.

별도 설치나 빌드 과정은 필요하지 않습니다.
